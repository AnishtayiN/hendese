۱-۱) ضرب ماتریس‌ها ✖️

ضرب (m×n) در (n×p) شدنی است و حاصل (m×p) می‌شود. یعنی ستون‌های اولی = سطرهای دومی باشد. درایه‌ها با «سطر در ستون» به دست می‌آیند.

A × B   شدنی ⟺   تعداد ستون‌های A = تعداد سطرهای Bحاصل یک ماتریس (سطرهای اولی × ستون‌های دومی) است
⛔ تله شماره ۱: ضرب ماتریسی جابه‌جایی نیست! یعنی در حالت کلی AB ≠ BA. اگر توی امتحان گفتی جابه‌جایی است، نمره‌ات پرید!
(AB)t = Bt At    |    (AB)-1 = B-1 A-1⚠️ ترتیب برعکس می‌شود! (جوراب و کفش: اول جوراب می‌پوشی، ولی اول کفش را درمی‌آوری 🧦👟)
📌 مثال حل‌شده (مدل امتحانی): حاصل ضرب را حساب کنید

1201- × 2130

  1. سطر اول در ستون اول: 1×2 + 2×3 = 8
  2. سطر اول در ستون دوم: 1×1 + 2×0 = 1
  3. سطر دوم در ستون اول: 0×2 + (-1)×3 = -3
  4. سطر دوم در ستون دوم: 0×1 + (-1)×0 = 0
✅ جواب: 813-0

۱-۲) دترمینان ۲×۲ و ۳×۳ (ساروس) 🧮

det = ad − bcبرای ماتریس [[a, b], [c, d]] : قطر اصلی منهای قطر فرعی

روش ساروس (فقط برای ۳×۳): دو ستون اول را سمت راست دوباره بنویس، حاصل‌ضرب ۳ قطر ↘ را جمع کن (+) و حاصل‌ضرب ۳ قطر ↙ را کم کن (−).

a(ei+...) − ... →   (aei + bfg + cdh) − (ceg + bdi + afh)برای [[a,b,c],[d,e,f],[g,h,i]]
📌 مثال حل‌شده: دترمینان ماتریس زیر؟

1201-12011

  1. دو ستون اول را تکرار کن: | 1 2 0 | 1 2 | و ...
  2. قطرهای ↘ : (1×1×1) + (2×2×0) + (0×(-1)×1) = 1 + 0 + 0 = 1
  3. قطرهای ↙ : (0×1×0) + (1×2×1) + (2×(-1)×1) = 0 + 2 − 2 = 0
✅ جواب: 1 − 0 = 1

۱-۴) وارون ماتریس ۲×۲ 🔄

شرط وارون‌پذیر بودن: دترمینان مخالف صفر باشد. فرمول حفظی:

A-1 = (1/det A) × «جای a و d عوض، علامت b و c عوض»یعنی: [[a,b],[c,d]]-1 = 1/(ad−bc) × [[d, −b], [−c, a]]

۱-۵) حل دستگاه با کرامر 🎯 (مهم‌ترین سؤال فصل!)

برای دستگاه دو معادله دو مجهول، دترمینان ضرایب را D بنام. بعد ستون جواب‌ها را یک‌بار جای ستون x بگذار (Dx) و یک‌بار جای ستون y (بگذار Dy):

DxD = x    ،    DyD = yشرط جواب یکتا: D ≠ 0
📌 اگر D = ۰ شد چی؟ آن‌وقت: اگر Dx یا Dy مخالف صفر بود ← دستگاه ناسازگار (بی‌جواب) است. اگر همه صفر شدند ← بی‌شمار جواب (معمولاً) دارد. دستگاه همگن (طرف راست همه صفر) همیشه جواب صفر دارد و جواب غیرصفر دارد ⟺ D = 0.
📌 مثال حل‌شده (کرامر): دستگاه زیر را حل کنید

2x + y = 5
x − y = 1

  1. D = (2)(-1) − (1)(1) = −3 ≠ 0 پس جواب یکتا دارد ✔
  2. Dx = (5)(-1) − (1)(1) = −6 ← ستون جواب‌ها جای ستون x
  3. Dy = (2)(1) − (5)(1) = −3 ← ستون جواب‌ها جای ستون y
✅ جواب: x = −6/−3 = 2 ، y = −3/−3 = 1 — امتحان کن: 2(2)+1=5 ✔

⭕ فصل ۲: مقاطع مخروطی (دایره، بیضی، سهمی)

پرنمره‌ترین فصل امتحان! • کلیدش «مربع کامل» است

⭐ تکنیک مادر این فصل — مربع کامل: هر وقت معادله «باز شده» دادند (مثل x² + 6x + ...) باید مربع کامل کنی تا مرکز/رأس پیدا شود. فرمول جادویی: x² + bx = (x + b/2)² − (b/2)² — یعنی نصف ضریب x را به توان ۲ برسان، یک‌بار اضافه و یک‌بار کم کن. پایین ۳ بار تمرینش می‌کنیم 👇

۲-۱) دایره 🔵

(x − h)² + (y − k)² = r²مرکز (h, k) و شعاع r — ⚠️ علامت‌ها برعکس خوانده می‌شوند: (x−3) یعنی h = +3

فرم گسترده: x² + y² + Dx + Ey + F = 0 ← مرکز (−D/2, −E/2) و شعاع:

r = √( (D/2)² + (E/2)² − F )زیر رادیکال باید مثبت شود وگرنه اصلاً دایره نیست!

وضعیت خط نسبت به دایره: فاصله مرکز تا خط (d) را حساب کن و با شعاع مقایسه کن:

d = |ah + bk + c| / √(a² + b²)فاصله مرکز (h,k) تا خط ax + by + c = 0
مقایسهوضعیت خط و دایره
d < rخط دایره را در دو نقطه قطع می‌کند ✂️✂️
d = rخط بر دایره مماس است 👆 (یک نقطه مشترک)
d > rخط و دایره متقاطع نیستند (جدا از هم) 🚫
📌 معادله مماس حفظی: خط مماس بر دایره x² + y² = r² در نقطه (x₀, y₀) روی دایره: xx₀ + yy₀ = r² — فقط یکی از x و yها صفر می‌گیرد!
📌 مثال حل‌شده: مرکز و شعاع دایره x² + y² − 4x + 6y − 3 = 0 ؟
  1. مربع کامل برای x: x² − 4x = (x − 2)² − 4
  2. مربع کامل برای y: y² + 6y = (y + 3)² − 9
  3. جایگذاری: (x−2)² − 4 + (y+3)² − 9 − 3 = 0 یعنی (x−2)² + (y+3)² = 16
✅ مرکز (2, −3) و شعاع r = 4

۲-۲) بیضی 🥚

مجموع فاصله هر نقطه بیضی از دو کانون ثابت و برابر 2a (طول قطر بزرگ) است. همیشه a > b و:

c² = a² − b²    و    خروج از مرکز e = c/a (همیشه بین ۰ و ۱)⚠️ در بیضی منها! (c² = a² − b²) — قاطی نکن
معادله استانداردکانون‌ها روی …کانون‌هارأس‌های اصلی
x²/a² + y²/b² = 1محور xها (افقی ↔)(±c, 0)(±a, 0)
x²/b² + y²/a² = 1محور yها (عمودی ↕)(0, ±c)(0, ±a)
⭐ ترفند تشخیص در ۳ ثانیه: مخرج بزرگ‌تر = a² است و کانون روی همان محور می‌افتد. مثلاً x²/25 + y²/9 = 1 ← چون ۲۵ > ۹ پس a²=25 و کانون‌ها روی محور x هستند: c = √(25−9) = 4 یعنی (±4, 0) ✔
📌 مثال حل‌شده: در بیضی x²/16 + y²/25 = 1 کانون‌ها و خروج از مرکز؟
  1. مخرج بزرگ‌تر زیر y² است پس a² = 25 و b² = 16 و کانون روی محور y ↕
  2. c² = 25 − 16 = 9 پس c = 3
  3. e = c/a = 3/5
✅ کانون‌ها (0, ±3) و خروج از مرکز e = 3/5

۲-۳) سهمی 🏀

هر نقطه سهمی از کانون (F) و خط هادی (l) به یک فاصله است. رأس دقیقاً وسط کانون و هادی است. ۴ حالت استاندارد (رأس در مبدأ):

معادلهکانون Fخط هادیدهانه به سمت
y² = 4px با p>0(p, 0)x = −pراست ➡️
y² = −4px با p>0(−p, 0)x = pچپ ⬅️
x² = 4py با p>0(0, p)y = −pبالا ⬆️
x² = −4py با p>0(0, −p)y = pپایین ⬇️
⭐ ترفند حفظی: ۱) آن متغیری که توان ۲ دارد می‌گوید کانون روی کدام محور است (y² ← محور x). ۲) علامت جهت دهانه را می‌گوید. ۳) عدد کنار متغیر درجه ۱ را تقسیم بر ۴ کن تا p به دست آید. مثلاً y² = 12x ← 4p = 12 ← p = 3 ← کانون (3, 0)، هادی x = −3 ✔
⛔ تله شماره ۳: اگر معادله سهمی به فرم y = ax² + bx + c دادند (رأس نه در مبدأ)، حتماً مربع کامل کن تا به فرم (x−h)² = 4p(y−k) برسی؛ آن‌وقت رأس (h,k) و کانون (h, k+p) است.
📌 مثال حل‌شده: کانون و هادی سهمی x² − 4x − 8y + 4 = 0 ؟
  1. مرتب کن: x² − 4x = 8y − 4
  2. مربع کامل: (x − 2)² − 4 = 8y − 4 یعنی (x − 2)² = 8y یعنی (x−2)² = 8(y − 0)
  3. رأس (2, 0) و 4p = 8 پس p = 2؛ چون x² داریم، کانون روی خط قائم رأس است و چون علامت مثبت، به بالا ⬆️
✅ رأس (2, 0)، کانون (2, 2)، هادی y = −2

۳-۱) طول بردار و بردار یکه 📏

|v| = √(x² + y² + z²)بردار AB = مختصات B منهای A (مقصد منهای مبدأ 🎯)

۳-۲) ضرب داخلی (دات) و زاویه 📐

a · b = x₁x₂ + y₁y₂ + z₁z₂ = |a| |b| cos θمتناظرها را در هم ضرب کن و جمع بزن
چی می‌خواهیم؟فرمول
زاویه بین دو بردارcos θ = (a·b) / (|a||b|)
شرط تعامد (عمود بودن ⊥)a · b = 0
تصویر قائم a روی b (بردارش)((a·b)/|b|²) b
اندازه تصویر (عددش)|a·b| / |b|
⛔ تله شماره ۴: در فرمول تصویر، مخرج |b|² است (به توان ۲!) — خیلی‌ها توان ۲ را جا می‌اندازند. و دقت کن تصویر «روی» کدام بردار خواسته شده؛ همان در مخرج و انتهای فرمول می‌آید.
📌 مثال حل‌شده: اگر a = (2, −1, 2) و b = (1, 2, 2) ، زاویه بین‌شان؟
  1. a·b = (2)(1) + (−1)(2) + (2)(2) = 2 − 2 + 4 = 4
  2. |a| = √(4+1+4) = 3 و |b| = √(1+4+4) = 3
  3. cos θ = 4/(3×3) = 4/9
✅ cos θ = 4/9 (خود زاویه را معمولاً نمی‌خواهند، همین کسینوس کافی است)

۳-۳) ضرب خارجی (کراس) ✖️

حاصل یک بردار است که بر هر دو بردار عمود است. اندازه‌اش = مساحت متوازی‌الاضلاع ساخته‌شده روی دو بردار:

|a × b| = |a| |b| sin θ = مساحت متوازی‌الاضلاعمساحت مثلث = نصف آن: S = ½ |a × b| 🔺
a × b = −(b × a)   |   i×j = k ، j×k = i ، k×i = j⛔ جابه‌جایی نیست و قرینه می‌شود! (تله تکراری) — چرخه i → j → k → i را حفظ کن 🔄

روش محاسبه: دترمینان ۳×۳ با سطر اول i, j, k و سطرهای بعد مؤلفه‌های a و b (با ساروس حساب کن).

📌 حجم‌ها (سؤال محبوب طراحان!): حجم متوازی‌السطوح با یال‌های a, b, c برابر |(a×b) · c| است (اول کراس، بعد دات، آخر قدرمطلق). حجم چهاروجهی (هرم مثلثی) = ⅙ همین مقدار.
📌 مثال حل‌شده: مساحت مثلثی با رأس‌های A(1,0,0) ، B(0,1,0) ، C(0,0,1) ؟
  1. دو بردار از یک رأس: AB = (−1, 1, 0) و AC = (−1, 0, 1)
  2. ضرب خارجی با ساروس: AB × AC = (1×1 − 0×0 , 0×(−1) − (−1)×1 , ...) ← با دقت حساب کن: (1, 1, 1)
  3. |AB × AC| = √(1+1+1) = √3 و مساحت مثلث نصف آن است
✅ مساحت = √3 / 2

۳-۴) معادله خط در فضا 🛤️

خط گذرنده از نقطه (x₀, y₀, z₀) با بردار هادی u = (a, b, c) :

پارامتری: x = x₀ + at ، y = y₀ + bt ، z = z₀ + ctمتقارن: (x−x₀)/a = (y−y₀)/b = (z−z₀)/c
📌 وضعیت دو خط: اول بردارهای هادی را چک کن: اگر موازی (مضرب هم) بودند ← دو خط موازی یا منطبق‌اند (یک نقطه را امتحان کن). اگر موازی نبودند ← یا متنافر‌اند یا متقاطع (با مساوی گذاشتن پارامتری‌ها و سازگاری، نقطه تقاطع را پیدا کن).

۳-۵) معادله صفحه 🪞 (پای ثابت امتحان!)

صفحه گذرنده از نقطه (x₀, y₀, z₀) با بردار نرمال (عمود بر صفحه) n = (a, b, c) :

a(x − x₀) + b(y − y₀) + c(z − z₀) = 0فرم کلی: ax + by + cz + d = 0 که در آن (a, b, c) همان بردار نرمال است
فاصله نقطه (x₀,y₀,z₀) از صفحه ax+by+cz+d=0 :   |ax₀ + by₀ + cz₀ + d|√(a² + b² + c²)⛔ قدرمطلق صورت کسر را فراموش نکن!
وضعیتشرط (با بردار هادی خط u و نرمال صفحه n)
خط موازی صفحه ➖u · n = 0 (هادی بر نرمال عمود است)
خط عمود بر صفحه ⬇️u ∥ n (هادی مضرب نرمال است)
دو صفحه موازینرمال‌ها موازی‌اند (n₁ ∥ n₂)
دو صفحه عمودn₁ · n₂ = 0
📌 مثال حل‌شده: معادله صفحه‌ای که از A(1, 2, −1) بگذرد و بر بردار n = (2, −1, 3) عمود باشد؟
